# Microsoft Rocketbox occupation avatars

The VRM files in this directory are derived from Microsoft Rocketbox:
https://github.com/microsoft/Microsoft-Rocketbox

Selected source avatars were converted from the original FBX assets to
skinned glTF and then wrapped as VRM 1.0 for this Avatar Studio. Embedded
texture images may be resized for web delivery. The conversion does not
add facial morph targets that are absent from the source assets.
