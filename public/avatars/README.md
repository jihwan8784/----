# Built-in avatar files

모든 내장 VRM은 이 폴더 하나에 있습니다. 파일 이름만 보고 출처와 용도를 알 수 있게 정리했습니다.

- `valid-*.vrm`: Google VALID / TLTMedia 기반 현실형 VRM (CC BY 4.0)
- `rocketbox-*.vrm`: Microsoft Rocketbox 기반 직업형 VRM (MIT)
- `LICENSE_GOOGLE_VALID.md`: Google VALID 계열 출처/라이선스
- `LICENSE_MICROSOFT_ROCKETBOX.md`: Rocketbox 계열 출처/라이선스

예: `valid-male-medical.vrm`, `rocketbox-female-firefighter.vrm`, `rocketbox-male-pilot-for-astronaut.vrm`.
