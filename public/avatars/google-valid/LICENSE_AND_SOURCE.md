# Realistic VRM asset attribution

The VRM files in this directory are optimized copies of VRM 1.0 conversions from `TLTMedia/valid-vrm-avatars`, based on Google's VALID (Visually Aligned Inclusive Dataset) avatars.

- Original 3D avatars: Google VALID — https://github.com/google-research/google-research/tree/master/valid
- VRM conversion / ARKit blend shape integration: TLTMedia — https://github.com/TLTMedia/valid-vrm-avatars
- License: Creative Commons Attribution 4.0 International (CC BY 4.0) — https://creativecommons.org/licenses/by/4.0/
- Local modification: embedded textures resized to a maximum of 1024px for browser delivery. VRM humanoid mappings, meshes, expressions, materials, and extension metadata are retained.

Imported source variants: Asian M/F body type 1 in Casual, Business, Medical, and Utility outfits.
